# Letters requirements

Version: v0.1.0 · [简体中文](#简体中文)

Browse private application and recommendation letters by folder; select a template or a prepared document. The authorized user can search the collection, read plain text, and open PDFs or download other originals. An empty collection, unavailable connection and expired permission have different visible states. Changing the language preserves the current search and document.

The public release contains the client and its data contract. A private service authorizes the collection and each document request and supplies the current files. Keep document bytes, names, directory listings, drafts, generated documents and credentials off the public source tree. Temporary test fixtures use invented text.

## 简体中文

**书信需求 · v0.1.0**

按目录浏览私人申请信、推荐信与模板，定位到需要使用的文档。 获准用户可以查找文档、阅读纯文本、打开 PDF 或下载其他格式的原件。空目录、暂时无法连接和权限失效分别提示。切换语言保留当前搜索和文档。

公开发行物包含客户端及其数据合同。私有服务分别验证列表和单个文档的访问权限，提供当前文档。真实文档、文件名、目录清单、草稿、构建产物及凭据均保留在公开仓库之外。测试使用临时合成材料。
